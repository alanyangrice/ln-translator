# Glossary

Hard-constraint term choices the translator must follow. Curated from
the parallel corpus and refined as evaluation surfaces inconsistencies.

| Japanese | English | Notes |
|----------|---------|-------|
| マフラー | scarf | Not "muffler" |
| 共用スペース | living room | Shared apartment space |
| 仙台さん | Sendai-san | Always with honorific (Miyagi POV) |
| 宮城 | Miyagi | No honorific (Sendai POV) |
| ピアス | earrings | — |
| 「」 | 「」 | Preserve Japanese dialogue brackets |
| チェスト | drawers | Refers to a chest of drawers / dresser, never bare "chest" (which reads as the body part) |
| ペン | mechanical pencil | When the scene already established the writing implement as a mechanical pencil; otherwise context-dependent |
| カットソー | long-sleeved shirt | Normalize as plain "shirt" / "long-sleeved shirt"; never "cut-and-sew" or "cut-and-sew tee" (fashion-jargon translationese) |
| 喉を潤す | quench (one's) thirst | Idiomatic English; never the calque "quench (one's) throat" |
| 気の迷い | a lapse of judgment / a moment of weakness in judgment / lost (one's) senses | Implies a passing irrational impulse; not generic "weakness" or "confusion" |
| 家主 | the person/girl who lives here / the resident | When referring to whoever's room or apartment the scene is in (almost always Miyagi). Never "owner of the house" / "homeowner" / "landlord" |
| 恋人 | lover / partner / someone (I'm) dating | Default to gender-neutral; only render as "boyfriend" / "girlfriend" when the source explicitly specifies (彼氏 / 彼女) |
| お返し | a return gift / something in return | In White Day or gift-exchange contexts. Keep the reciprocal-gift specificity; do not flatten to vague "anything in return" |
| 鉄分補給 | (an) iron supplement / topping up your iron | In the blood-drinking running gag. Natural supplement framing; never the literal "replenish your iron" |
| クラス替え | changing classes / new class assignments / being put in different classes | The April school-year reshuffling. Never "class shuffling" or "class shuffle" (calque) |
| カモノハシ | platypus | Recurring stuffed animal / tissue-box cover Miyagi keeps in her room. Always plain "platypus" — never "Mr. Platypus", "duckbill", or other paraphrase |
| てるてる坊主 | teru teru bozu | Keep the Japanese transliteration (matches the hatsumode / kotatsu pattern already established in the corpus). Never "rain doll" / "weather doll" / "good-weather doll" |
| ハシビロコウ | shoebill | Standard English ornithological name for the bird Miyagi wants to see at the zoo. Never transliterate as "hashibirokou" |
| 第二関節 | second joint | Anatomical reference to the second knuckle of a finger. The corpus uses "second joint" 7× to "knuckle" 1×, so keep "second joint" for consistency |
| ティッシュカバー | tissue box cover | The novelty animal-shaped cover for a tissue box (Miyagi's platypus / crocodile ones). Use "tissue box cover" when the cover itself is the subject; "tissue box" is fine when the distinction doesn't matter |
| 桔梗ちゃん | Kikyou-chan | Sendai's middle-school tutoring student (Hanamaki Kikyou). Always with -chan, romanized without macron (not "Kikyō-chan") |
| 家庭教師 | tutor / private tutor | Default to plain "tutor"; use "private tutor" only when contrasting with classroom teaching or the in-home nature is foregrounded |
| 呼び捨て | calling someone by their first name | Default to the social act ("call me by my first name" / "calling her by just her first name"). "Without an honorific" / "drop the honorific" is fine only when the sentence explicitly discusses Japanese address mechanics |
| 敬語 | polite speech / formal speech | Use natural EN phrasing for speech level ("talking so formally", "drop the polite speech"). Avoid over-technical "honorific language" unless discussing the linguistic system |
| 馴れ馴れしい | too forward / overly familiar | Social-boundary judgment. "Too familiar" is acceptable, but "too forward" often reads more natural in dialogue |
| 距離感 | sense of boundaries / sense of personal space | Social distance, not physical distance. Never "sense of distance" in relationship/dialogue contexts |
| コミュ力 | social skills | Casual shorthand for communication/social ability. Avoid literal "communication power" or overly strong "messed up" unless source register is that strong |
| 紅茶とセット | with black tea / cheesecake and black tea set | Café ordering phrase. Never "tea set" by itself, which reads as tableware |
| よそいきの顔 | customer-service face / public-facing expression / work-mode smile | A social mask or public-facing role, especially at work. Avoid generic "kind/polite smile" unless the JP specifically says smile |
| バイト | part-time job / work / shift | Context-dependent. Avoid bare "jobs" when it sounds like separate employment; use "work" for the general topic, "part-time job" when introducing it, and "shift(s)" when scheduling is foregrounded |
| 家庭教師のバイトを増やす | take on another tutoring student / pick up more tutoring work | In the tutoring-money subplot, the established concrete action is taking on another student. Avoid vague "more jobs" unless the JP is clearly talking about multiple jobs |
| 私のもの | mine / belong to me | Miyagi's possessive motif. Preserve the blunt possessive force; do not soften into generic relationship language |
| いうことをきく | do what [person] says / listen to [person] | In Miyagi's ownership/order logic, prefer "do what I say" when obedience is the point. "Listen to me" is acceptable only when ordinary listening, not compliance, is meant. Avoid heavier BDSM/servitude wording like "submit" unless the JP explicitly supports it |
| 命令 | order | Relationship motif and hard term. Do not flatten to "request" or "favor" |
| お願い / リクエスト | request / favor / order | Usually softer than 命令, but in the Miyagi-Sendai "what do you want me to do?" dynamic it can continue the established order motif. If Sendai is inviting Miyagi to name what she wants done, prefer "give me an order" / "tell me what to do" over "request." Otherwise keep "request" / "favor". Never use stagey "take requests" |
| 鍋 | hot pot | Use "hot pot" in ordinary narration/dialogue. Avoid unexplained "nabe" unless a scene explicitly foregrounds the Japanese term itself. |
| 水炊き | mizutaki hot pot / chicken hot pot | On first mention, "mizutaki hot pot" is acceptable if the specific dish matters; afterward use "hot pot" when the scene is just referring to the meal. |
| 土鍋 | clay pot | Cooking vessel for hot pot. |
| 白菜 | cabbage / napa cabbage | Prefer plain "cabbage" in casual narration unless the specific ingredient distinction matters. "Napa cabbage" is accurate but can sound grocery-label formal. |
| 水菜 | mizuna greens / greens | Prefer "greens" in casual meal narration; use "mizuna greens" only if the specific vegetable matters. Avoid unexplained bare "mizuna". |
| ラムネ | ramune candy / ramune soda | Disambiguate by context: in snack lists with chips/chocolate/pudding, use "ramune candy"; when drinking from a bottle, use "ramune soda". Never confuse with ramen. |
