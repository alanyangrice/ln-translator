# Rule

Restructure Japanese grammar into natural English syntax only when the source shape would otherwise make the English sound translated, stiff, overloaded, or unclear. Preserve the source's meaning, agency, emotional progression, and scene logic, but do not preserve Japanese word order, modifier order, or clause order when English needs a different shape.

This rule applies at the sentence-architecture level. It complements `rule-000-06`: that rule says to avoid translationese; this rule says how to rebuild Japanese sentence shapes into fluent English.

## Core Decision

When a draft sentence feels awkward, first identify the English relationship between linked clauses, modifier stacks, or scene beats:

- join it if the beats form one natural action or thought
- subordinate it if one beat explains timing, cause, manner, condition, or contrast
- split it if one sentence becomes overloaded, rambling, or mechanically coordinated
- compress it if the source uses multiple verbs or nouns for one ordinary English action
- reframe it if Japanese uses an abstract, topic-comment, or noun-heavy structure that English would express through a person, action, or scene judgment

Splitting is a repair, not a default style. Do not turn clean English narration into fragments just because the Japanese uses short clauses, line breaks, repeated counts, or fronted time/setup phrases.

If a retrieved precedent or nearby reference phrasing is already fluent, casual, and context-matching, prefer that established phrasing over inventing a more formal rewrite.

For simple setup-plus-action narration, make the action clear before optimizing rhythm. Time markers, repeated counts, object placement, and routine physical setup should attach to the action when detaching them would make the English feel like notes rather than narration.

For modifier phrases that describe a person or object through an image already active in the scene, choose the natural English continuation of that image instead of translating the modifier as a standalone label.

## Watch For

- repeated coordination holding together unrelated beats
- source clause order treated as mandatory English order or emphasis
- setup, time, count, or modifier phrases stranded away from the action they explain
- body-part, object-handling, or movement phrasing preserved only because it appears in the Japanese
- abstract or noun-heavy Japanese phrasing that needs a human, action, or scene subject in English
- formal or label-like wording replacing the narrator's plain thought
- culturally specific wording chosen where the established translation uses a plain everyday object word
- local image or metaphor continuity lost because a later modifier was translated in isolation

## Avoid

- chaining every source beat with "and"
- breaking every source beat into its own sentence
- keeping every source clause in one English sentence when the result rambles
- adding motives, emotions, or facts while restructuring

## Self-Check

Would this sentence sound like the established translator's casual English if it had originally been written in English? If it feels accurate but stiff, rebuild the sentence without making the diction more formal than the reference voice.
